# فسيلة — Pharmacologie générale, Partie 1

موقع مراجعة عربي (RTL) لطالب التمريض، مبني من درس **Pr. KHARCHOUFA Loubna، ISPITS Beni Mellal، annexe Khénifra، 2025–2026**. يحتوي على 11 فصلًا مكتملًا، 107 مصطلحات و55 سؤالًا. النصوص الفرنسية الأصلية والرسوم من ملف الدرس متاحة داخل الفصول.

## تشغيل محلي

لا توجد حزم تشغيل أو إطار أو خطوة بناء. من جذر المشروع:

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000`. أو استخدم أي خادم ملفات ثابتة، مثل امتداد Live Server. فتح `index.html` مباشرة عبر `file://` لا يسمح عادة بتحميل ملفات JSON ووحدات ES.

## GitHub Pages

1. ارفع الملفات إلى مستودع GitHub؛ احتفظ بـ `index.html` و`assets/` و`data/` و`source/` في الجذر.
2. من **Settings → Pages → Build and deployment** اختر **Deploy from a branch** ثم الفرع و`/ (root)`.
3. افتح رابط Pages الذي يعرضه GitHub. جميع مسارات الملفات نسبية؛ يعمل الموقع أيضًا تحت `/repository-name/`، والتوجيه عبر `#/` لا يحتاج إلى إعداد خادم.

لا يلزم تفعيل أي خدمة مدفوعة، أو إعداد متغيرات سرية، أو تشغيل `npm install`. الملف `.nojekyll` مرفق.

## تنظيم المشروع

```text
index.html                 هيكل RTL والتنقل
assets/styles.css          الألوان، التجاوب، الحركة، والطباعة
assets/app.js              الصفحات والتوجيه والبحث والبطاقات
assets/core.js             العزل اللغوي والحفظ والوظائف المشتركة
assets/animations.js       رسوم SVG وCSS والتفاعلات
assets/quiz.js             الأسئلة والتصحيح والنتائج
assets/theme.js            المظهر قبل الرسم لتقليل الوميض
assets/source-*.webp       الرسوم الأصلية من الشرائح
source/*.pdf               ملف الأستاذة، المرجع الأصلي
data/chapters.json        فهرس الأجزاء والفصول وأهداف الوحدة
data/c1.json … c11.json    ملف مستقل لكل فصل
data/glossary.json        المعجم
data/quiz.json            بنك الأسئلة
scripts/                   فحوص اختيارية للمطور
```

## إضافة الجزء الثاني — JSON فقط

1. أضف مثلًا `data/p2-c1.json` بنفس بنية `c1.json`، مع `"id":"p2-c1"` و`"partId":"p2"`. اكتب الشرح والمصطلحات الفرنسية بين `{{ }}`؛ يعرضها المصيّر داخل `<bdi lang="fr" dir="ltr">`. النص يُهرَّب قبل العرض، فلا تضف HTML خامًا.
2. أضف سطرًا واحدًا إلى مصفوفة `chapters` في `data/chapters.json`:

```json
{"id":"p2-c1","partId":"p2","file":"p2-c1.json","titleAr":"عنوان الفصل","titleFr":"Titre du chapitre","minutes":15,"order":1}
```

بوجود فصل له، يصبح الجزء متاحًا تلقائيًا. لا يلزم تعديل JS. تتبع الملخصات والتنقل والبحث والتقدم الفهرس تلقائيًا.

3. أضف مصطلحاته إلى `glossary.json` وأسئلته إلى `quiz.json` مع نفس `chapterId`؛ هذه إضافة بيانات فقط. لكل فصل خمسة أسئلة في بنك هذا الجزء.
4. للرسوم استخدم نوعًا موجودًا، أو النوع العام `sequence` مع `steps`:

```json
{"type":"sequence","title":"رحلة الفكرة","caption":"خطوات تساعدك على الفهم.","steps":["{{Terme}} — المعنى وشرح بسيط","الخطوة التالية"]}
```

للفصل الحقول: `id`, `partId`, `order`, `titleAr`, `titleFr`, `minutes`, `intro`, `sections`, `animations`, `summary`, `sourcePages`, `originals`. القسم يتضمن `title` و`paragraphs`، واختياريًا `items`, `note`, `table`. يمكن أن تضم `originals` نصوص المصدر الفرنسي الجديدة مع أرقام الصفحات، ويمكن تعيين `sourceFile` في ملف الفصل لربطه بملف PDF جديد بدل ملف الجزء الأول.

المصطلح: `fr`, `ar`, `simpleExplanationAr`, `chapterId` و`exampleFr` اختياري. السؤال: `id`, `chapterId`, `type`, `prompt`, `explanation`، و`extra:true` لأي إضافة. الأنواع: `mcq` و`boolean` مع `options` و`answer` (فهرس يبدأ بـ0)، و`complete` مع `answer` نصي، و`matching` مع أزواج `{fr,ar}` في `pairs`.

## المحتوى والمراجعة

- اعتُمد ملف PDF الموجود في `source/` (86 صفحة). بقيت تعريفات الأستاذة الفرنسية كما استُخرجت منه في كتل قابلة للطي. يُرجع إلى صورة الشريحة عند تعذر استخراج رسم أو جدول.
- نُقل جدول الشريحة 81 بنصه وحواشيه، وأُرفقت صورته أيضًا. وُضعت عبارة **حسب جدول الدرس**؛ لا يدّعي الموقع تحديث التشريع الحالي.
- شُرحت نقاط الغموض بعلامة **ملاحظة للتوضيح**، خصوصًا السواغ، وموانع الطريق الوريدي في الجدول، وإعادة التحضير، ومدة الاستغلال والبراءة.
- التمارين الرمزية والتفسيرات الإضافية مميزة بـ **إضافة للتوضيح**. رسم الحقن للمراجعة النظرية وليس تدريبًا عمليًا.
- أهداف الصفحة الأولى هي أهداف الوحدة بأجزائها الأربعة؛ المتاح حاليًا هو الجزء الأول.
- الخط: Tajawal عبر Google Fonts، مع خط عربي محلي بديل عند تعذر الشبكة. يحتاج تنزيل الخط أول مرة إلى اتصال؛ المحتوى والرسوم نفسها محلية.
- التقدم والنتائج والمفضلة وبطاقات المراجعة والمظهر محفوظة في `localStorage` على هذا المتصفح. فشل التخزين لا يمنع التعلّم، ويظهر تنبيه. لا يُرسل الموقع بيانات الطالب إلى خادم.

## التحقق

```sh
node scripts/validate.mjs
```

ويمكن، اختياريًا، تشغيل فحص المنطق داخل نموذج DOM باستخدام `node scripts/dom-qa.mjs` بعد تثبيت `node-html-parser` كأداة تطوير. هذا لا يختبر العرض أو الإتاحة في متصفح.

يفحص فحص البيانات الفهرس، اكتمال بيانات كل فصل، ربط المصطلحات، الأسئلة الأربعة الأنواع، التصحيح، وجود الرسوم والمصدر، ووجود المصطلحات المطلوبة. لا يحتاج إلى تثبيت أي حزمة.

للفحص في متصفح على جهاز يسمح بتشغيله، ثبّت أدوات التطوير اختياريًا خارج متطلبات تشغيل الموقع:

```sh
npm install --no-save --package-lock=false playwright-core axe-core lighthouse
# عيّن مسار Chrome / Chromium على جهازك
CHROME_PATH=/path/to/chrome node scripts/browser-qa.mjs
```

شغّل الخادم المحلي أولًا. يفحص السكربت عرض 360px وعرض الحاسوب، الفصول والاختبارات والبحث والحفظ والمظهر والطباعة، ثم يحفظ لقطات ونتائج axe في `test-results/`. يمكن تحديد `BASE_URL`، بما فيه مسار مستودع Pages، و`QA_NODE_MODULES` إذا ثُبّتت الأدوات خارجيًا.

لـ Lighthouse على جهازك:

```sh
CHROME_PATH=/path/to/chrome npx lighthouse http://localhost:8000 --only-categories=accessibility --chrome-flags="--headless" --output=html --output-path=test-results/lighthouse.html
```

راجع أيضًا لوحة المفاتيح وVoiceOver/NVDA، وخيار تقليل الحركة، والبحث بالعربية والفرنسية، وبطاقة المراجعة، وانتهاء المؤقت، ومعاينة طباعة 11 صفحة A4.

**حدود التحقق في بيئة الإنشاء:** قيود النظام منعت فتح منفذ HTTP وتشغيل Chromium (`Operation not permitted`). لذلك لا نعلن نتيجة Lighthouse ≥90 أو نجاح الفحص البصري على 360px. أُنجزت فحوص البيانات والمنطق المتاحة؛ نتائجها مفصلة في `QA.md`.

## سجل الالتزامات

كان المجلد `.git` الموفَّر فارغًا وللقراءة فقط. لذلك حُفظ تاريخ Git في `.history/git` داخل مساحة العمل، مع التزام مستقل لكل فصل:

```sh
git --git-dir=.history/git --work-tree=. log --oneline
```

المجلد `.history` مستثنى من ملفات الموقع. توجد نسخة قابلة للنقل في `pharma-history.bundle`؛ يمكن استعادتها إلى مجلد جديد:

```sh
git clone pharma-history.bundle pharma-restored
```

هذا الموقع للمراجعة فقط، والمرجع هو درس الأستاذة ودروس المعهد.
